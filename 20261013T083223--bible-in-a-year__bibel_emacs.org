* Links zu anderen Posts und Headline

Dafür verwende ich den typischen org-link =[[file:mein-anderer-post.org][anderen Beitrag]]=. 

- Im Org-Mode :: Der Link funktioniert direkt in Emacs.
- Beim Export (.md) :: ~ox-hugo~ konvertiert dies automatisch in einen relativen Markdown-Link (z. B. =[anderen Beitrag](../mein-anderer-post/)=).
- In HTML :: Hugo rendert daraus den fertigen HTML-Link.

Um einen Link zu einer Headline in einem Post herzustellen, muss ich zuerst im verlinkten Post unter der gewünschten Headline ein ~org-set-property~ (=C-c C-x p=) setzen.

#+begin_src org
 * Eine wichtige Unterüberschrift
  :PROPERTIES:
  :CUSTOM_ID: mein-anker-punkt
  :END:
  Text unter der Überschrift...
#+end_src

Der Link dorthin sieht folgendermaßen aus: =[[file:mein-anderer-post.org::#mein-anker-punkt][spezifischen Abschnitt]]=. Wichtig ist dabei der doppelte Doppelpunkt =::#=.
